A fun little login form where a panda covers its eyes when you type your password.  
Built with pure **HTML, CSS, and JavaScript** — no frameworks, no libraries.  

🔗 **Live Demo:** [Click here](https://subhajit-maji.github.io/Panda-login-form/)

---

## ✨ Features
- Cute CSS panda that reacts when you focus on the password field  
- Simple, lightweight, and responsive  
- No external dependencies  

---

## 🚀 How to Use
1. Open the [demo](https://subhajit-maji.github.io/Panda-login-form/).  
2. Click on the password field.  
3. Watch the panda cover its eyes!  

Want to run it locally?  
```bash
git clone https://github.com/subhajit-maji/Panda-login-form.git
